Detailed Description

Plain-C# level-pacing invariant checks — shared by LevelPacingConfiguration's editor-only OnValidate warnings and EditMode test coverage, so authoring checks and test checks can't drift by verifying the same invariants two different ways.

Returns one issue message per problem found; an empty list means the config is clean.

levelsToCheck bounds the non-monotonic-threshold scan (0 skips it) — the caller derives this from its own scoring curve, since that data isn't on the interface.
