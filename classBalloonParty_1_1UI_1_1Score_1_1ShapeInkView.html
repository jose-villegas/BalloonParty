Detailed Description

Draws one score shape as a single mesh: the shape's baked wire mesh with the ink shader (BalloonParty/Sprite/ShapeInk), which places the pens and paints the ink behind them from the numbers written here each frame.

Stands in for a pooled trail per pen. Built and pooled in code by ShapeInkPool; it has no prefab.
