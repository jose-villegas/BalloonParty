Detailed Description

A SightReaction that eases a continuous value every frame off the probe's raw centrality (0 = off-aim, 1 = dead-centre) — the shape for speed/scale/emission/tint reactions.

Subclasses implement OnSightTick; the per-frame poll (over a subscription) is deliberate since the ease runs every frame regardless.
