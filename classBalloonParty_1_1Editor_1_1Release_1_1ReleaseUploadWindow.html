Detailed Description

Editor window that builds three APK variants (release, release+cheats, development), tags the commit, generates a changelog, and uploads everything to GitHub as a release.

Build provenance is enforced by three layers:

  1. The working tree must be clean (no uncommitted changes).
  2. Commit SHA + git tree hash are baked into each APK via BuildInfo.json.
  3. SHA-256 checksums of every APK are published in the release notes.
