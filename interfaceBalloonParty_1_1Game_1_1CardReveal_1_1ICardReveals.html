Detailed Description

The reveals a stage plays, one at a time.

A stage (the reveal's view) attaches while it's on screen; with none attached nothing is queued, and the tooltip names the cards instead.

void BalloonParty.Game.CardReveal.ICardReveals.Finish ( RevealedCard done)

The stage is done with done : if it's still Current, the next queued reveal, if any, starts.

A reveal a reset or detach already dropped finishes nothing, so a stage still animating it can't cut off the reveal that replaced it.
