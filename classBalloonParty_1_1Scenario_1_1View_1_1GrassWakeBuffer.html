Detailed Description

The grass's own short memory of the disturbance field, published as the global _GrassWakeTex the blades bend to.

The shared field holds a push for seconds and spreads it (the clouds' slow drift); the wake keeps only what the field gained each frame and lets it go on its own recovery (Hidden/BalloonParty/Scenario/GrassWake), so the blades answer the ball at once and stand back up quickly. Field-sized and in the field's UV space, so the blades sample both the same way. One small blit and one copy a frame, only while the ground shows.
