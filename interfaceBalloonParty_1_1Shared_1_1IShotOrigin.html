Detailed Description

Where shots come from and how big the ball is, for the board-side code that plans or resolves against a flight and cannot reach into the thrower's own scope.

The thrower fills it in when it starts (ThrowerOriginProvider).

◆ RestingPivot

Vector2 BalloonParty.Shared.IShotOrigin.RestingPivot
get

The point the cannon turns about when it is at rest.

The muzzle sits straight ahead of it along the aim, so the line of every shot, whatever its angle, passes through this one point.

Captured once, when the thrower starts, and not read off the cannon as it stands: the cannon rises half a unit as it enters and is punched back by each shot's recoil, and a layout planned in either moment would be planned for a cannon that is not there when the level is played.

Implemented in BalloonParty.Thrower.ThrowerOriginProvider, and BalloonParty.Thrower.ThrowerOriginProvider.
