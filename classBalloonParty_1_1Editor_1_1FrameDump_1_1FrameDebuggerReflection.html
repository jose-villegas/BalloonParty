Detailed Description

Shared reflection plumbing for reaching into the internal UnityEditorInternal.FrameDebuggerInternal.FrameDebuggerUtility / FrameDebuggerEventData types.

Both the text dumper and the per-step screenshot walker resolve the same members through here, so the type/member names live in exactly one place.
