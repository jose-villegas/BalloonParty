Detailed Description

How a chance roll forgives a player in trouble (Game/Assist/PityRoll): each roll it misses while the player is in need raises the next one, in proportion to that need, until a hit.

Property Documentation

◆ GrowthPerMiss

float BalloonParty.Shared.IPitySettings.GrowthPerMiss
get

How much each roll missed at full need raises the chance, in multiples of the base chance: 4 takes a 1% chance to 5%, then 9%.

A miss at half need counts half. 0 = no pity.

Implemented in BalloonParty.Configuration.PitySettings.
