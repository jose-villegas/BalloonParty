Detailed Description

A trial look (IToughSnakeSpringSettings): a spring between each pair of neighbours in the tough snake, tied to their knots.

Each link is a SpringChain drawn as a line, so it sags while the pair stands side by side, stretches as the one ahead steps away and swings as the one behind catches up. A link lives as long as the same pair stands next to each other in the snake.
