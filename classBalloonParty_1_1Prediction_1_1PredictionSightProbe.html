Detailed Description

Single per-actor producer of the "is the loaded shot's aim-prediction line sighted on this actor, and how centrally" signal.

Owns the polyline-vs-circle trace test — run once per frame, skipped whenever neither the trace nor the target moved since the last evaluation — and publishes it for any number of composed consumers: TraceHitMarker and item reactions (see BalloonParty.Item.SightReaction), so none of them re-trace. Pooled/non-DI: the host hands it an IProjectileFacingSource via Configure.
