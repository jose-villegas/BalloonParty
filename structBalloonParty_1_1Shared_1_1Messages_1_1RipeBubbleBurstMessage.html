Detailed Description

Published by RipeBubbleService when a ripe cluster bursts.

Neighbours says which neighbouring balloons the burst touched (a ripple's hits that landed, the foam's new coats), one bit per direction in the order HexCoordinates.HexNeighborIndices lists the six neighbours of Slot, so a burst carries them without allocating. Reached is how many. A foam also carries its hand-out (Handout): where each of its bubbles went, in the order they leave, one 4-bit entry per bubble (a direction, plus 8 for a cluster, or 15 for a leftover) and the count in the seventh. Published before the hand-out changes the board, so the views still see it as it was.
