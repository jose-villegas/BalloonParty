Detailed Description

Keeps in memory only the pop sheets the reveal needs: the one playing and the one the next reveal will play (Game.CardReveal.ICardReveals.NextPop), loaded ahead while the game plays so a reveal starts on time.

Each sheet is several megabytes, so all of them loaded with the scene would be tens. Read from Resources by the paths in the settings; a sheet let go is unloaded, or, if it's still loading, as soon as it arrives.
