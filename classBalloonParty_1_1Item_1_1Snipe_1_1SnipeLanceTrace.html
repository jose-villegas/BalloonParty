Detailed Description

Where each Snipe-armed shot's current straight run began: the point it armed at, then each wall it carries the lance past.

Pure bookkeeping, so the pencil line's segmenting is tested headless.

Assumes a piercing shot only turns at walls: every balloon a pierce meets pops or is plowed, none deflects it. A deflector that bent a piercing shot mid-run would need to close the run there too.

Ends the open run at wall , reporting where it began.

A lance still armed past the wall starts its next run there; otherwise the shot stops being tracked. True only for a run the lance discharged on: the line marks where the lance was spent, so a run that merely carried it to a wall, with nothing plowed, draws nothing. Also false when no run was open, or the run is too short to draw.
