Detailed Description

The cruise knobs, mirroring ProjectileMotionResolver/ProjectileView exactly (see ShotSimulator's cruise handling).

Default (all-zero) disables cruise entirely — WallBounceThreshold <= 0 is the same "0 disables" convention IProjectileFlightConfig.CruiseWallBounceThreshold uses. The per-bounce tap ANIMATION (target speed scaled by curve(elapsed/duration), the freeze-then-pickup beat) never bends the path, so the event sim folds it into TapLagSeconds — the time an eased startup loses versus flying the whole segment at the target speed: duration × (1 − mean curve value) — added to the timeline once per cruise bounce.
