Detailed Description

Read surface for the LIVE ambient scene light — the current time-of-day state the runtime owner (TimeOfDayService) drives and publishes as shader globals.

Consumers that need the value CPU-side (the sky tint, the GI magnitude reference) read here rather than the static ISceneLightSettings, so a runtime sweep reaches them. The static/edit-time fallback still lives on the settings asset.
