Detailed Description

Live IEffectBoard over a real SlotGrid — occupants are every IBalloonModel on the grid (statics are never IBalloonModel, so they're excluded for free) minus the popped host and minus any view whose collider is currently disabled (BalloonView.HasActiveCollider — mid-despawn, e.g.).

Position comes from the view transform (balance/nudge displace it); viewlessRadius only ever backs a slot with no live view, keeping this EditMode-testable against a headless grid the same way ShotBoardGather already reads it.
