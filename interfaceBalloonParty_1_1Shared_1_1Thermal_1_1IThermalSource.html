Detailed Description

Latest polled thermal readings for ThermalFrameRateGovernor.

Implementations cache values between polls because the Android headroom API is rate-limited (see AndroidThermalSource); callers may read these properties every frame cheaply.

float BalloonParty.Shared.Thermal.IThermalSource.Headroom
get

Android PowerManager.getThermalHeadroom semantics: normalized thermal headroom where 1.0 is the severe-throttling threshold and lower values are cooler.

Returns the most recently polled value. When the API is unavailable it returns NaN, which implementations map to 0 here (treated as fully cool) so the governor never down-steps on a missing signal.
