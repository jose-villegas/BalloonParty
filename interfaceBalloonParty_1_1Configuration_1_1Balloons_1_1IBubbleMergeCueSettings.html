Detailed Description

How a bubble merge looks: the bubbles a giver passes on while it stays hop one by one to the receiver, which wobbles and splashes as each lands.

A giver absorbed whole flows in (IBalloonsConfiguration.BubbleMergeSeconds) and the receiver takes it in the same way when it arrives.
