Detailed Description

Single per-item producer of the "is the loaded shot's aim-prediction line sighted on this item, and how centrally" signal.

Owns the polyline-vs-circle trace test (run once per frame) and publishes it for any number of composed consumers — reactions (see SightReaction) and the facing rotator — so none of them re-trace. Pooled/non-DI: the host hands it an IProjectileFacingSource via Configure.
