Detailed Description

Solver-side IEffectBoard — runs purely over the working set + ShotSlotLattice (Shot Solver Accuracy Phase C: "runs on the working set.

  • HexCoordinates only — NOT the dynamics grid"), so an item core selects identically whether or not <c>ShotBoardDynamics</c> is present. A handle is the occupant's own index into <see cref="Occupants" /> (see <see cref="EffectOccupant.Handle" />'s doc) — <see cref="SlotOf" /> resolves it back to the stable <see cref="ShotBalloonState.SlotIndex" /> the caller actually needs to re-find the occupant in a working set a prior hit's swap-remove may have reordered.
