◆ BuffModifierOp

enum BalloonParty.Projectile.Model.BuffModifierOp

How a buff's value is combined with other modifiers targeting the same stat.

Evaluation order: base + Flat → × (1 + Additive sum) → × Multiplicative product.

Enumerator
Flat 

Added directly to the base value before percentage scaling.

Additive 

Summed with other additives, then applied as (1 + sum) multiplier. E.g. two +0.2 = ×1.4.

Multiplicative 

Each multiplicative modifier multiplies independently. E.g. two ×2 = ×4.

enum BalloonParty.Projectile.Model.SpeedTransitionKind

Which speed change is currently playing out.

Both are the same eased blend toward the tap count's target speed, differing only in where they start: a tap beat starts from a standstill (the deliberate freeze-then-pickup punctuation of earning a tap), an arm ramp from the speed the shot was already travelling at (so arming accelerates instead of snapping to top speed).
