Detailed Description

Item-carrier selection + params for the shot solver (Shot Solver Accuracy Phase C) — selection and outcome computation ONLY; ShotSimulator stays the sole mutator of flight/board state (mirrors dynamics's split: this layer never touches ShotBalloonState directly).

A FIFO queue mirrors the live frame cadence (a popped item's own effect can enqueue another activation — a chained item pop — which resolves on a later iteration, breadth-first, exactly like ItemActivator's per-frame draining). MaxActivationsPerFlight bounds a pathological chain (e.g. bomb-chains-into-bomb) so a sweep of thousands of angles can never spin forever. Wired per sub-phase (C1 Shield .. C6 Snipe) — an item type with no core (Shield, Snipe) never touches _effectParams/_effectBoard at all; every other branch still returns a no-op outcome and no hits until its own sub-phase lands.
