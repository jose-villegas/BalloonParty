IProjectileModel BalloonParty.Projectile.ProjectileRegistry.ShotOrCurrent ( IProjectileModel shot)

The shot an effect should land on.

A given shot is returned only while it is alive, never swapped for another ball. With no shot (an effect no ball set off), the latest in flight, else the loaded one.
