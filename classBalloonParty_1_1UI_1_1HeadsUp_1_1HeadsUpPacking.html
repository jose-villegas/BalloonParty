Detailed Description

Where a new heads-up line goes so it doesn't sit on the lines still showing: the nearest spot to where it happened, stepping out in rings of one line height up and down and half a line width sideways, kept inside the canvas.

When the board is too crowded for a clean spot it takes the one that overlaps least, so a burst still reads instead of stacking into one smudge.
