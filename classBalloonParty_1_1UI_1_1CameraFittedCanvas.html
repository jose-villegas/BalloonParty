Detailed Description

Keeps a World Space canvas over the main camera's view, sized and scaled the way a Screen Space canvas with a UnityEngine.UI.CanvasScaler would be (scale with screen size, matching between width and height), so a layout authored for the game canvas lands in the same place on screen.

It is world geometry all the same: the main camera draws it among the board's sprites, sorted by its sorting layer, so it sits under the screen-space light and goes through the same post-processing, and cameras that render its layer (the light's scene capture) see it. Follows the camera's zoom and pan every frame.
