◆ Complete()

void BalloonParty.Shared.Pool.TrailFlight.Complete ( )
package

Jumps the trail to completed state so onComplete fires immediately.

Idempotent: once the flight is Idle the pooled instance may already be flying for a NEW group, so completing again would fire someone else's arrival — a stale holder's Complete must be a no-op.
