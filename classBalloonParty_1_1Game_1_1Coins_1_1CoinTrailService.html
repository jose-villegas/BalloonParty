Detailed Description

Flies each dropped coin from its pop to the coin counter and publishes CoinLandedMessage when it lands, which is when the wallet counts it.

With no counter registered (a scene without the HUD, the tests) a coin lands at once. Coins still flying when the run resets or the board changes land at once too. They fly on real time: a coin is headed for the HUD, so it keeps moving through the level-up popup's pause and the loss's slow motion. Only closing the game mid-flight loses one.
