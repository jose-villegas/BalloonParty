Detailed Description

The three balance-bias formulas (color-diagonal, line, clump) shared by every IBalanceInfluence.WeightBias override — live models and (later) sim stub actors run the identical formula because both implement IBalanceBiasSource.

Counts same-type balloons along the best-aligned hex axis through candidate .

For each of the three hex axes, walks both directions and counts consecutive same-type occupants. Returns the max across axes — rewarding candidates that extend an existing line (wall) rather than forming a lump.
