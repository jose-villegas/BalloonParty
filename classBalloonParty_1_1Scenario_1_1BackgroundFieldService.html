Detailed Description

Owns the shared cloud field: bakes one scrolling cloud-density map into a camera-sized RT on a cadence timer (ICadencedEffect, bypassed during camera transitions) and publishes it — plus its world bounds — as global shader properties, so every consumer reads the SAME map with a single tap (the BackgroundCloud backdrop, sprite drop-shadows, the GI/light smear, the wall net).

A plain-C# DI singleton exactly like its siblings DisturbanceFieldService / SceneLightFieldService: bounds come from IGameDisplayConfiguration (entry-point-independent — no camera, so the Launcher's additive-load dual-camera boot can't confuse it), the cloud roll is tuned on the blit material (IBackgroundFieldSettings.DensityMaterial), and there is no scene GameObject to place or duplicate. GPU side: Shaders/BalloonParty/Include/BackgroundField.cginc (consumers) + BackgroundFieldGen.cginc and the BackgroundFieldDensity blit (generation).
