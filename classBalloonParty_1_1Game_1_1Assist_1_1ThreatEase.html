Detailed Description

Eases the threats that come by chance while the player is in need: a threat's chance scaled down by IAssistSettings.ThreatEaseAtFullNeed times the need, so the last heart sees fewer of them and a healthy run sees them all.

The need rides along for the picks that favour help.
