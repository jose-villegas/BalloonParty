Detailed Description

A SightRampReaction that points a GlitterSwirl material's _Drift along the incoming shot — the specks stream in the direction the aim is travelling as it crosses this item, rather than the material's fixed authored drift.

Reads BalloonParty.Prediction.PredictionSightProbe.SightDirection directly (not the centrality SightRampReaction otherwise passes to OnSightTick) via the shared SightReaction.Probe. Writes via a MaterialPropertyBlock (mirrors PredictionSightSpiral), so the shared material asset stays untouched.
