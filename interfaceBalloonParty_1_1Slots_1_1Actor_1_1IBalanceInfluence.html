Detailed Description

Lets a dynamic actor shape how the balancer moves it: a per-candidate weight offset added to the support-based score (e.g.

a tendency away from same-type neighbours), a per-rebalance step allowance so heavier actors visibly rise slower, and an intervention order so faster actors win contested slots each round.
