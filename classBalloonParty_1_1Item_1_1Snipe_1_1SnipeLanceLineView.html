Detailed Description

One pencil stroke along a Snipe lance's run, carrying the aim trace's smoke-and-glitter material so the shot's path reads in the same carbon hand as the cannon's aim.

The line is built from chunks of a fixed length, each its own two-point LineRenderer, so the erase can wipe them away one at a time. Driven entirely by SnipeLanceLines; it only renders what it is told.
