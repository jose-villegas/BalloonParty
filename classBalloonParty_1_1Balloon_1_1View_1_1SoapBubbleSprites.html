Detailed Description

Loose soap bubbles, one per sprite, for the views that send bubbles off on their own (BubbleMergeView, RipeBubbleBurstView).

Each is a plain SpriteRenderer under the owning view, disabled and kept when returned, so a busy board reuses them rather than creating one each time. The caller that rents a bubble returns it.
