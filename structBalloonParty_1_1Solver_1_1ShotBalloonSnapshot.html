Detailed Description

One board actor as the solver sees it — enough to reproduce pop/deflect/score rules without a live IBalloonModel.

Grown by composition (Shot Solver Accuracy §3): a geometry/scoring core, a ColorProfile, an optional BalanceProfile (null ⇒ no dynamic stub backs this entry — see ShotBoardDynamics's null-Actor gating), a ShotContactKind, and an optional ItemProfile (data-only in this phase — the item layer reads it starting Phase C1). A plain balloon may wear foam (Coat) and a bubble cluster may be Ripe. Construct via the named factories, never the (private) field-order constructor directly — that is what keeps every caller's field mapping honest as the struct grows.

The nuke reward balloon: a plated balloon that dents.

Only the shot's ordinary hit dents it: it deflects and costs a hit, and the last one arms it instead of popping it. A pierce plows it while it has more than one left and arms it, and a piercing item effect (a bomb's blast, a laser) arms it. Armed, it deflects every ball and stays on the board. Plain item damage never wears it (ShotSimulator.ApplyEffectHits). Mirrors NukeBalloonModel.

A plated reward balloon: colourless, deflecting every ordinary hit forever (int.MaxValue, so a pierce plows it and the discharge pops it), and scoreless.

Item effects treat it as an unbreakable: a piercing one (a bomb's blast, a laser) pops it, plain damage never wears it down. Mirrors PlatedBalloonModel.

A collision-only archetype with no score and no balance-grid presence — Phase A's interactive statics (Deflector/Gatekeeper/Absorber).

Balance is always null: statics never enter the balance grid as movers, so no dynamic stub backs them (see the null-Actor gating in ShotBoardDynamics/ShotSimulator); slotIndex is the actor's REAL grid slot, carried via StaticSlotIndex so a pop/deflect can still address the right cell.

◆ StaticSlotIndex

readonly? Vector2Int BalloonParty.Solver.ShotBalloonSnapshot.StaticSlotIndex

The static archetype's own slot — set only by ForStaticContact.

A static never carries a Balance (statics never enter the balance grid as movers), so this is the sole source of slot identity for ShotBalloonState.SlotIndex on a static entry; without it, every static would default to (0,0) and corrupt whatever legitimately occupies that slot on RemoveFromGridAt/OnBalloonHitAt (the 0b-review landmine).
