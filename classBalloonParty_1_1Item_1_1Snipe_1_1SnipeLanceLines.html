Detailed Description

Draws a carbon pencil line along the straight run a Snipe lance is spent on, the moment the shot discharges at the wall that ends it.

The run starts where the lance armed (or at the last wall it carried the lance past) and the line traces it start to wall, holds, then fades. Cruise-earned pierces draw nothing: only a Snipe opens a run.
