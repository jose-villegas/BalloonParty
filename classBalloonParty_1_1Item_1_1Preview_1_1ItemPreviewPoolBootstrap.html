Detailed Description

Registers and pre-warms the HighlightTrail pen pool to IItemPreviewConfig.MaxPens — the same hard ceiling ItemPreviewTicker already never exceeds — so the first telegraph never instantiates a pen mid-frame.

Mirrors SfxVoicePoolBootstrap: a cap that doubles as the prewarm count, read from injected config.
