Detailed Description

Keeps ActiveScenario on the current level's scenario (sky or ground, per ILevelPacingConfiguration.ScenarioForLevel).

Snaps on run start and run reset, so the start-level cheat and a restart land on the right backdrop, and switches as a level-up Ascent starts. The switch is a cut for now; the edge that rides the scenario root in is PLAN-TerrainBiomes.md phase 2.
