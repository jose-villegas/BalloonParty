Detailed Description

One item type's config-free effect snapshot — ItemSettings and PaintSettings etc.

are plain [Serializable] classes with no public constructor a test can build, so every core (BombBlast/LaserCross/ LightningChain/PaintSpread) reads this immutable value snapshot instead. Damage/Flags are per item type (Bomb/Laser/Lightning deal 3, everything else 1 — see ItemSettings.Damage); the other five fields only matter for the item type they name.
