Detailed Description

Bakes the catalogue a meadow level's mushroom walls are dealt from (MushroomWallCatalogue): draws candidate boards to the placement limits, turns away the ones that crowd the cannon (CannonViewOf), flies each of the rest from every angle the thrower can aim at with the shot simulator, and keeps the ones inside the settings' band.

A level then picks a layout and flies nothing, which is why this is done here and not at the deal.

A layout is kept by what it measures, not by its shape: walls that send the ball to each other arm on more angles and in wider windows than walls that do not, and the band is what tells them apart. A candidate is kept only when it is inside the band with room to spare (ArmingMarginAngles, WindowMarginAngles). The bake, the Editor's tests and the game on a device run on three runtimes that round a flight differently, and a ball that grazes a cap on one misses it on another, so a layout measures a few angles apart between them: the room is wider than the drift the tests allow an entry, so one that drifts as far as allowed is still inside the band.

The same Measure flies every entry again in an EditMode test, against what ships.
