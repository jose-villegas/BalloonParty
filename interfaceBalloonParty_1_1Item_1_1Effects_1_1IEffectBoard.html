Detailed Description

The occupant read-set an item-effect core selects against — implemented by GridEffectBoard (live) and ShotSimEffectBoard (solver), so the same core (BombBlast/LaserCross/LightningChain/PaintSpread) runs identically over either.

Deliberately has no hex-neighbour helper — HexCoordinates is pure and already reachable from every core in this assembly.
