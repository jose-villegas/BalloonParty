Detailed Description

Stub grid actor standing in for a live balloon in the dynamic-board sim — enough of IWriteableDynamicSlotActor, IBalanceInfluence and IBalanceBiasSource for the real BalancePlanner to move it exactly as the live balancer would (plan_shot_geometry §7b), including the gathered actor's per-type balance-bias/omnidirectional behaviour (Shot Solver Accuracy §3 "Weight-bias sharing" — WeightBias runs the identical shared formula a live model would).

Also carries the balance-motion segment and nudge-impulse list the moving-circle contact solve reads (§7c).

Vector2 toPosition )

Starts (or extends) the balance path for a pulse.

A NEW pulse starts from the FULL centre — balance position plus the live nudge offset — because that is what the game does: BalloonBalancer.StartBalanceTween seeds waypoint 0 with the view's current position (wobble included), and BalloonMotionTicker then adopts each tween write as the new base and re-adds the CURRENT impulse offset on top — so a tween starting mid-wobble briefly double-carries the start offset, converging to lattice+impulses as the path proceeds. A repeat call from the SAME pulse chains the hop as an extra waypoint, mirroring RecordPath building the multi-waypoint DOPath — except for direct movers, whose live tween skips intermediates (FinalWaypointBuffer), so the last waypoint is overwritten instead.
