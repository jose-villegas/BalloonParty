enum BalloonParty.Shared.SceneLight.SceneLightMode
package

How a consumer reads the scene light.

Values match the shader convention the light helpers branch on (Full = 0, Ambient = 1, Local = 2).

Enumerator
Full 

The field: global ambient + any local point/area lights.

Ambient 

The global scene light only (colour × intensity); ignores the field.

Local 

Only local field lights above the ambient — neutral until a light is near.
