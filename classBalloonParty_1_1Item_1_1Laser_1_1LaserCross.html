Detailed Description

Config-free Laser cross-selection core (Shot Solver Accuracy Phase C3) — runs identically over GridEffectBoard (live) and ShotSimEffectBoard (solver), mirroring LaserItemHandler.CastCross/ConvertBorderingNeighbors's geometry exactly, minus the beam/light/telegraph presentation and Physics2D itself (the board's own IEffectBoard.Occupants already excludes the popped host — see GridEffectBoard.Rebuild/ShotSimEffectBoard.Bind).

Four arms along the rotated ±right/±up directions (a pure 2D rotation of Vector2.right/Vector2.up by rotationDegrees — mirrors laserRotation * Vector3.right/Vector3.up for a pure Z-axis rotation quaternion, see LaserItemRotation's own Quaternion.AngleAxis(_angle, Vector3.forward)).

Each arm is a swept-circle corridor: an occupant hits iff the segment-to-centre distance is within LaserCrossParams.CastRadius plus its own radius, at an entry distance in [0, LaserCrossParams.CastDistance] — INCLUDING an occupant already overlapping at the origin (Unity's own CircleCast reports a start-overlap as an immediate hit). Every unique occupant hits ONCE even if two arms cross it. A rainbow host additionally converts every surviving, paintable, not-already-hit hex neighbour of each hit occupant.
