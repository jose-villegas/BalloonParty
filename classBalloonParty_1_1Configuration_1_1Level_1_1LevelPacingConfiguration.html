Detailed Description

Per-colour points-required per level.

The _scoringCurve defines cumulative score milestones; the per-colour bar at each level is the delta from the previous milestone split across that level's active colours, rounded to a clean multiple.

Upper bound on how many of a balloon type can share the board across every range — the pool prewarm size.

Uncapped ranges (0 cap) scale to their board size (columns × the range's max board lines). Returns 0 for a type no range gates in.
