Detailed Description

Two popups for a MetricBinding: which snapshot, then which value out of it.

The value list is generated from MetricCatalog/TimerCatalog, so adding a metric row makes it selectable here with no edit to this file.

Deliberately a property drawer on the struct rather than a custom editor for MetricLabel — Unity reuses a property drawer for each element of an array, so the day a label needs several values this file does not change at all.
