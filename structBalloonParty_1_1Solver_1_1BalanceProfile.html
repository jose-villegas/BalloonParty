Detailed Description

Balance-grid identity/behaviour for a snapshot target — absent (null on the owning ShotBalloonSnapshot) for a target with no live dynamic stub (e.g.

a Phase A interactive static). Omnidirectional/BiasKind/BiasValue/ BiasTypeId are gather-populated from the actor's IBalanceInfluence/ IBalanceBiasSource (Phase B) so the sim's stub actors reproduce the live weight system.
