Detailed Description

Publishes _BP_UnscaledTime as a global shader property so an effect can opt out of the engine's scaled clock.

Shaders have _Time, which is scaled — anything driven by it freezes while Time.timeScale is 0, which is precisely when the level-up popup wants its fill to keep shining.

Opt-in per material (_ShineUnscaledTime), so every effect that has always run on scaled time keeps doing so. See Include/ShineSweep.cginc.
