Detailed Description

Plays a rising chime run once the aim's prediction line settles on a "chain" of item-hosting balloons — every item host ItemSightTracker currently reports, in the order it reports them (first-to-last along the trace).

Gated on IItemPreviewConfig.SightSoundSettleSeconds, the same settle-before-reacting shape SightDelaySeconds already uses for the visual telegraph: a fast sweep across several items stays silent until the aim actually stops, rather than retriggering on every transient frame the raw sighted chain happens to take on its way there. Whenever the SETTLED chain then changes — a new item joins the path, one drops off the end, or the aim settles on an entirely different chain — the whole thing replays from its first item through to its last as an ascending run, so a chain that grew reads as one continuously re-confirmed phrase rather than a single new note tacked onto an old one. Unlike every other router in this folder, this one doesn't translate an existing MessagePipe message — nothing publishes "a balloon was sighted" today — so it reads ItemSightTracker's already-detected chain every Tick instead of subscribing.
