Detailed Description

Pure, seeded answer to "is this level in the sky, on the ground or over water, and how far into that stretch?

". Sky until <see cref="FirstGroundLevel" />, rolled between <see cref="ScenarioScheduleSettings.GroundFromLevel" /> and <see cref="ScenarioScheduleSettings.GroundByLevel" />, then a ground stretch of a fixed <see cref="ScenarioScheduleSettings.FirstGroundStretch" />, then sky and surface stretches alternate, each lasting a rolled number of levels in its own range. Every later surface stretch is water or a meadow by its own roll (<see cref="ScenarioScheduleSettings.WaterShare" />), made after its length, so water changes which surface a stretch shows but never where the stretches fall. Every roll hashes with the schedule's salt mixed with the run's seed, so each run lays out its own surfaces and sky, and within a run the same level always gets the same answer, so a retry keeps it. A run seed of 0 is the schedule with no run mixed in, for the editor preview and tests.
