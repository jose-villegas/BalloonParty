Detailed Description

A run saved at a level boundary, so a run the OS killed can be picked up on the next launch.

It holds what the saved level began with (score, hearts, cards), the run's seed and the retries it has used, so resuming plays that level as its retry would, without spending a retry. Saved on the game-over screen, it brings that screen back instead, with the same offer.
