Detailed Description

Orders a set of sighted item hosts first-to-last along the trace they were found on — the sequence ItemRangePreviewController steps a multi-host telegraph through.

Pure geometry, factored out of the controller so the interesting case — a bent, multi-segment trace, where a host spatially near the aim's own origin can still sit late in true arc-length order — is edit-mode testable without the controller's grid/pool machinery, mirroring ItemPreviewEntry's own separation from ItemPreviewTicker. Orders by each host's own projection onto the trace (ItemPreviewEntry.TryFindNearestPointOnPolyline), never by Centrality — how squarely the line crosses a balloon says nothing about how far along the line that balloon sits, which is the only thing a sequence cares about.
