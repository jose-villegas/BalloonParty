◆ BloomDuration

float BalloonParty.Configuration.IItemPreviewConfig.BloomDuration
get

Seconds the figure's FURTHEST-travelling pen takes to reach its dash slot, so every figure — however large — completes its draw-in in the same time.

Nearer pens cover less arc under the same shared clock and so arrive sooner, which is what makes the figure read as drawing itself in one stroke at a time rather than fading in all at once.

◆ DashLength

float BalloonParty.Configuration.IItemPreviewConfig.DashLength
get

Target world length of a dash, feeding stride = DashLength + DashSpacing, which in turn derives each stroke's dash count.

Not the literal painted length — the gap is the pinned quantity (see DashSpacing), so the dash a pen actually paints is slot − DashSpacing and absorbs the per-stroke rounding error instead. Universal across every figure — dashing is the one drawing style, not a per-item opt-in — so a Bomb circle and Shield's stub target the same dash size.

Implemented in BalloonParty.Configuration.ItemPreviewConfig.

◆ DashSpacing

float BalloonParty.Configuration.IItemPreviewConfig.DashSpacing

World length of blank arc between dashes — the pinned quantity a pen's gap always equals exactly, regardless of stroke length, because rounding the dash count per stroke means the slot is never exactly the stride; pinning the gap rather than the dash is what makes two strokes of different length (e.g.

Laser's two corridors) read as the same dash pattern. 0 reproduces a solid line: the stride collapses to DashLength, so each pen's slot equals its painted length and adjacent dashes touch with no gap — the zero-spacing case, not a separate continuous mode.

◆ MaxPens

int BalloonParty.Configuration.IItemPreviewConfig.MaxPens
get

Hard ceiling on pens summed across a figure's strokes AND their approach cascades (the dashed comet tail each leading leg draws in with).

A stroke's own dash count is derived from its length, so a large figure (Laser's two ~40-unit corridors, ~160 units of combined perimeter) would otherwise ask for hundreds of pooled TrailRenderers. Past this cap every stroke's dashes are spaced out together instead of any part going undrawn — the figure's own dashes claim their share first, so a long approach can only ever spend what the figure didn't need.

Implemented in BalloonParty.Configuration.ItemPreviewConfig.

float BalloonParty.Configuration.IItemPreviewConfig.SightDelaySeconds
get

Seconds a host must stay continuously sighted before its figure first appears.

Restarts whenever the sighted host changes, so sweeping the aim across a row of items shows nothing until it settles on one. 0 shows the figure the instant a host is sighted, reproducing the old no-delay behaviour.
