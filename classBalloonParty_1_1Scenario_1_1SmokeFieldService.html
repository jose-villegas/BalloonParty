Detailed Description

Owns the smoke field: a persistent screen-space RT that accumulates palette-colored stamps and decays them over time.

Publishes the RT as global shader properties (_SmokeTex, _SmokeBoundsMin/Size) so any consumer can sample it. Architecture mirrors DisturbanceFieldService / SceneLightFieldService: plain-C# DI singleton, no MonoBehaviour, ping-pong blit pipeline.
