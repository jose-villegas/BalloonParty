Detailed Description

Owns the smoke field: a persistent screen-space RT that accumulates palette-colored stamps and decays them over time.

Publishes the RT as global shader properties (_SmokeTex, _SmokeBoundsMin/Size) so any consumer can sample it. Architecture mirrors DisturbanceFieldService / SceneLightFieldService: plain-C# DI singleton, no MonoBehaviour, ping-pong blit pipeline. On a paper (bonus) level (IActiveScenario) a second field runs beside it, the ink: sources whose profile is on the PaintLayer.Ink layer (pops, the Paint item) stamp there instead, wider, each newer stroke covering what is under it, and never decay. It is published as _InkFieldTex (same bounds), and the paper draws it into the page. The smoke itself is the same on paper as anywhere.
