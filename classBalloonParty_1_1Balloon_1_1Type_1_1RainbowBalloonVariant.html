◆ PushBands()

void BalloonParty.Balloon.Type.RainbowBalloonVariant.PushBands ( IGamePalette palette,
int allowedColorsMask )
package

Pushes the banded colours for an explicit palette + allowed-colours mask via a MaterialPropertyBlock — the EDITOR bands preview only (edit mode has no DI and no resolver, so it feeds the palette asset directly and overrides the unset globals).

At runtime the colours are GLOBAL (set once per level by LevelDifficultyResolver), so this per-renderer push is not on the runtime path.
