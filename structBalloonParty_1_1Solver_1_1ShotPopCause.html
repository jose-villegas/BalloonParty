Detailed Description

One pop's scoring identity — replaces the ad-hoc bool seams ResolvePopScore used to read straight off ShotFlightState (Shot Solver Accuracy Phase C §1.5).

IsProjectileContact gates BOTH colour adoption and the shield refund — an item- triggered pop (Bomb/Laser/Lightning) never steals the projectile's colour and never refunds, mirroring ProjectileHitResolver's adoption/refund running only off its own direct-contact path (an item's DamageContext dispatch never touches projectile.ColorName or the streak tracker's refund gate). SourceColorId is the PRE-adoption projectile colour for a projectile contact, or the item's own host balloon's colour for an item-triggered one (mirrors BombItemHandler's balloon.GetColorId() becoming every dispatched hit's DamageContext.SourceColorId) — the anchor a rainbow target or a source-colour-paying (Unbreakable) target both read.
