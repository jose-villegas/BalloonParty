Detailed Description

Hides the decorated field in the inspector unless a sibling enum field (on the same serialized object or struct) currently equals one of Values.

Pass the enum's integer constants, cast at the call site — e.g. [ShowIfEnum(nameof(_source), (int)Source.Realtime)]. Assumes a contiguous 0-based enum (value == declaration index). Don't combine with another drawer attribute (e.g. [Range]) — Unity uses only one property drawer per field. Editor-only behaviour: ShowIfEnumDrawer.
