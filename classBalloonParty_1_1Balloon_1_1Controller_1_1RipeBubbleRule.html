Whether a cluster whose fuse ran out can coat this neighbour: a plain balloon (ICoatable, item carriers and rainbows included) wearing fewer than maxLayers , never a reward balloon.

Toughs, unbreakables and grid actors take none: only the plain balloon wears a coat. A neighbouring cluster takes a bubble instead (ClusterRoom).

The folding cluster's scale over its own while it shows shown of the from bubbles it started with.

The shader packs fewer bubbles closer in, so the scale makes up for it and the cluster keeps its outline, growing a little more each step: at one bubble it is a single bubble FoldedSize times the size of the whole cluster it was. bubbleRadius is the material's (SoapBubbleShader.BubbleRadiusOf).

static int BalloonParty.Balloon.Controller.RipeBubbleRule.PlanHandout ( int bubbles,
int[] coatRoom,
int[] clusterRoom )
staticpackage

Where a cluster whose fuse ran out hands its bubbles (at most RipeBubbleBurstMessage.MaxHandout), encoded as RipeBubbleBurstMessage.Handout.

One bubble per taker a round, in direction order, coats (coatRoom , layers each plain neighbour can still take) before clusters (clusterRoom , bubbles each neighbouring cluster can still take); rounds run until the bubbles or the room run out, and any bubbles left over pop as leftovers. Both arrays are indexed by direction and used up as the plan takes from them.

Whether a ripple hits this neighbour: a balloon, as an item's hit would, other than a reward balloon or one that bounces an ordinary hit (the unbreakable, a tough with more than one hit left), whose Deflect would act on the shot that set the ripple off.

Other clusters are hit, ripe ones too.

static bool BalloonParty.Balloon.Controller.RipeBubbleRule.Throbs ( float before,
float after,
float fastSeconds )
staticpackage

Whether a ripe cluster's fuse throbs as it runs from before seconds left to after : once as it crosses each whole second, and each half second in the last fastSeconds .

A step that crosses two beats throbs once; a fuse that holds (the level clock stopped), runs back up (ripening) or has run out (the burst takes over) does not throb.
