Detailed Description

Makes the heads-ups' pencil font in one step: the Patrick Hand TMP font asset (created by TMP's own "Font Asset > SDF" command, so it matches one made by hand) on the pencil text shader, then sets it on the tooltip's label.

Running it again reuses the existing font asset and only re-assigns it.
