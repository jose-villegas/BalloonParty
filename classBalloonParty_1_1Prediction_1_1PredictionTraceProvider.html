Detailed Description

Shared reference to the current aim-prediction trace, decoupled from direct access — mirrors BalloonParty.Projectile.ProjectilePositionProvider.

Readers (e.g. per-actor hit markers) poll Version instead of subscribing, so 50+ pooled views can cheaply skip work on frames where the trace hasn't changed.
