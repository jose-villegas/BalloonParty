Detailed Description

The hex-lattice geometry an item effect core needs, snapshotted once — no SlotGrid/dynamics reference, so it stays constructible in an EditMode test.

SlotPosition reproduces SlotGrid.IndexToWorldPosition's forward mapping bit-for-bit (both call the same HexCoordinates.IndexToWorldPosition).
