Detailed Description

Static logging facade with per-tag coloring in the Unity Console.

Info and Assert are decorated with [Conditional("UNITY_EDITOR"), Conditional("DEVELOPMENT_BUILD")], so they compile out of release builds automatically — no #if guards needed.

Important: pass interpolated strings directly as arguments (Log.Info("Tag", $"value {x}")). Do not hoist them into a local variable first — the compiler strips the entire call including argument evaluation, but a pre-assigned variable would still allocate.
