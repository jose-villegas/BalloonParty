Detailed Description

Static hand-off (like Navigation) for the launch "ascend" cloud-scroll, so the Launcher's Play trigger can drive the Game-scope cloud field without cross-scene DI: the trigger Begins the roll, waits Duration, then transitions to Game — so the game doesn't appear until the initial scroll finishes.

BackgroundFieldService reflects this into its cloud world offset; nothing else needs to know.
