Detailed Description

Resolves the internal Frame Debugger reflection surface once and exposes typed per-event reads for the walker.

Unity's native side only populates FrameDebuggerEventData for the event at the current FrameDebuggerUtility.limit, so TryReadEventData is a polling API: the caller scrubs the limit, pumps the player loop, and retries until the data reads as ready for the requested index.
