Detailed Description

Holds this frame's impacts (every outward disturbance stamp: a ball's steps, pops, bombs, balloons gliding in) for the water's ripples until GroundView reads them in its LateUpdate.

ImpactEventBus clears in VContainer's LateTick, which runs before MonoBehaviour LateUpdate, so the view can't read the bus itself; this copies it after Update, when the frame's fixed steps and updates have all reported.
