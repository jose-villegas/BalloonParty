Detailed Description

Config-free Lightning chain-selection core (Shot Solver Accuracy Phase C4) — runs identically over GridEffectBoard (live) and ShotSimEffectBoard (solver), mirroring LightningItemHandler.CollectSortedTargets/Activate's selection exactly, minus the chain/glow/light presentation.

Unlike Bomb/Laser, selection is grid TOPOLOGY, not physical overlap — matches read EffectOccupant.SlotPosition (the lattice home), never EffectOccupant.Position.

Starting at center , searches outward in concentric hex rings for the nearest occupant with a concrete (non-rainbow, non-empty) colour — mirrors BalloonModelExtensions.FindNearestColorId's ring walk exactly (same corner/side/step traversal, same odd-row offset↔cube conversion), over board instead of a live SlotGrid (IEffectBoard.SearchRadius stands in for Mathf.Max(grid.Columns, grid.Rows); IEffectBoard.TryGetOccupantAt stands in for grid.At/IsEmpty/InBounds — a missing/out-of-bounds slot returns false either way).

No explicit exclude parameter: the board already excludes the popped host (same reasoning as Resolve's own hostSlot doc). Returns null if no concrete colour exists on the board.

Every occupant whose EffectOccupant.ColorId equals matchColorId (a plain string match — mirrors CollectSortedTargets's own gate exactly, with no separate rainbow exclusion; callers guarantee matchColorId is already a concrete colour), distance-ordered nearest-first from origin over lattice EffectOccupant.SlotPosition (mirrors _grid.IndexToWorldPosition-based sorting — topology, not live view transforms).

EffectHit.Group carries each match's jump index in that order. A normal host (convertsToRainbow false) emits a EffectHitKind.Damage hit per match, unconditionally (mirrors the live handler's own unconditional _hitDispatcher.Dispatch call). A rainbow host instead CONVERTS — emits EffectHitKind.Recolor to rainbowColorId for every EffectOccupant.IsPaintable match only (mirrors the live handler's own model is IPaintable guard); a matched-but-not-paintable occupant still consumes a jump index (the chain still visits it) but produces no hit. hostSlot is unused by the selection itself — the board already excludes the popped host (see ShotSimEffectBoard.Bind/GridEffectBoard.Rebuild's own exclusion) — and is kept only for signature symmetry with BombBlast/LaserCross.
