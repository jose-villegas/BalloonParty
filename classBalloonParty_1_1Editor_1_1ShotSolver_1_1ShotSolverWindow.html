Detailed Description

Sweeps aim angle against the live board (see plan_shot_geometry) and reports the windows that reach a target score — the editor half of the shot-geometry solver, Task 2.

Critical-angle enumeration (exact tangency breakpoints, plan §2) is v2; this sweeps N samples and refines each window edge by bisection instead.

◆ AimAngleStepDegrees

float BalloonParty.Editor.ShotSolver.ShotSolverWindow.AimAngleStepDegrees
getprivate

0 = continuous aim.

Read from the project's ProjectileFlightConfig asset rather than the live DI container — cheap enough for every OnGUI call, and matches ThrowerController.QuantizeAimDirection's notion of "reachable" regardless of whether a sweep has gathered the live board yet.
