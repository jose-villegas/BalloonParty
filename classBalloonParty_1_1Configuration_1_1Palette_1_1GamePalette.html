◆ RainbowColorId

const string BalloonParty.Configuration.Palette.GamePalette.RainbowColorId = "__rainbow__"
static

Reserved color id for the "all colors" wildcard (the rainbow balloon).

Never a palette entry — a balloon carrying this has no concrete color, so colour interactions can detect it via IsRainbow instead of acting on an arbitrary spawn colour.
