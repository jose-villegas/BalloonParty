Detailed Description

Config-free Paint blob-selection core (Shot Solver Accuracy Phase C5) — runs identically over GridEffectBoard (live) and ShotSimEffectBoard (solver), mirroring PaintItemHandler.CollectPaintTargets/TryClassify/NearestBlob's bucketing exactly, minus the drip/flight/disturbance-stamp presentation.

Selection is grid TOPOLOGY, not physical overlap (like LightningChain) — every occupant is bucketed against its NEAREST packed blob over EffectOccupant.SlotPosition (the lattice home), never EffectOccupant.Position, mirroring the live handler comparing _grid.IndexToWorldPosition(slot) against each blob centre.

A EffectOccupant.ResistsPaint occupant (tough/unbreakable) and any other non-EffectOccupant.IsPaintable occupant never produce an EffectHit here — the live handler still plays a drip on a resist occupant (PaintItemHandler.ApplyPaint's own accept/reject split), but that is presentation the sim never models, and PaintItemHandler is deliberately NOT repointed onto this core (unlike Bomb/Laser) — it keeps its own CollectPaintTargets/TryClassify for its own reject/drip bookkeeping. A future repoint that wants the drip list back can read EffectOccupant.ResistsPaint straight off IEffectBoard.Occupants instead of this core emitting anything for it — no EffectHitKind exists to represent "no recolour, just cosmetics" anyway, so inventing one now would be speculative.

Every paintable occupant whose colour differs from paintColorId (mirrors TryClassify's accept branch — the same plain-string-equality check that also skips an already-rainbow balloon when the holder itself paints rainbow) AND whose colour is NOT the rainbow wildcard (a rainbow balloon resists concrete paint — only a rainbow holder, having the same id, matches above and short-circuits) is bucketed to its SINGLE nearest blob centre in blobPositions ; a bucket farther than blobRadius from every blob is dropped entirely (mirrors CollectPaintTargets's own nearestSqr > radiusSqr gate).

Emits one EffectHitKind.Recolor per accepted occupant to paintColorId , with EffectHit.Group set to that nearest blob's index.
