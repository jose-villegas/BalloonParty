Detailed Description

Tracks which item-hosting balloons the aim's prediction line currently crosses, ordered first-to-last along it — the single place that answers "what is sighted right now" so a consumer (today, Audio/Routing/ItemSightSoundRouter) reads one shared, already-walked answer instead of re-running its own grid walk.

Logs to the console every time the sighted structure itself changes (see LogIfChanged), purely as a debugging aid for watching what the aim is actually crossing without guessing from a downstream effect.
