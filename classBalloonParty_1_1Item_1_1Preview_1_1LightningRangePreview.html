Detailed Description

Lightning's telegraph: the chain — an arc from the host to its nearest same-colour target, then on from each target to the next.

Targets and their order come from LightningChain itself, run over a live GridEffectBoard, so the drawn chain visits exactly the balloons the effect would and in the same nearest-first order. Positions are each occupant's SlotPosition (the lattice home) because that is what the core sorts by — Lightning's selection is grid topology, not physical overlap.

Resolved with convertsToRainbow: false even for a rainbow host. That flag decides what a match SUFFERS (damage vs recolour), and a rainbow host's non-paintable match still consumes a jump but emits no hit — reading the rainbow hit list would silently drop links from the drawn path. False makes every match emit in jump order, which is the chain's shape.

Known gap: a rainbow host live matches the PROJECTILE's colour when it has a concrete one, falling back to the nearest concrete colour on the board. The telegraph only does the fallback, so a rainbow host under a coloured shot draws the wrong chain (Item Range Preview open questions).
