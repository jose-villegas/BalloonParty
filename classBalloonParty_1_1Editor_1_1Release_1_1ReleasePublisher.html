Detailed Description

Creates the GitHub release and uploads the APKs, talking to the REST API directly.

This was a bash script (Tools/upload_release.sh) invoked as /bin/bash, which cannot resolve on Windows, and which needed jq — not shipped with Git Bash — so fixing only the interpreter path just moved the failure a few lines down. Doing it in C# needs nothing installed beyond what the editor already has.

It also keeps the token out of a process command line. The old call passed it as an argument, so any crash dump printed it in full — which is exactly how one leaked.
