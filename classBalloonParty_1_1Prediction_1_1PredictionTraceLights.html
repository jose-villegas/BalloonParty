Detailed Description

Optional capsule (segment) lights mirroring the prediction line while the player aims — one per trace leg (the calculator emits corner points only: launch, each wall bounce, the top-wall tip), so the lights bend exactly where the line does.

Gated entirely by IPredictionTraceConfig.LightingEnabled; every call is a no-op when it's off, so a caller can wire this in unconditionally. Intensity and half-width are tunable from launch to tip via IPredictionTraceConfig.LightFadeCurve/IPredictionTraceConfig.LightWidthCurve, sampled at each leg's arc-length position. Lights register when the trace appears, are mutated in place on every aim update (re-registering per frame would churn the field), and are disposed when the trace clears.
