Detailed Description

Takes the launch screen's Continue (IRunResumeRequest) and resumes the saved run while the launch screen is still up: stages it as a retry of its level that spends no retry, and resets the run.

A run saved on the game-over screen goes back to it once the game shows. Leaving the launch screen any other way starts a new run, which drops the save.
