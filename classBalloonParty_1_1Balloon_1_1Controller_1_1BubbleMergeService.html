Detailed Description

Merges bubble clusters that sit in neighbouring slots (BubbleMergeRule).

Whenever the grid has changed (a spawn, a pop, the board settling), the next frame looks at every pair of neighbouring clusters whose bubbles fit in one: the smaller flows into the larger, which holds both counts. Each cluster merges at most once a pass; the absorb itself changes the grid, so a cluster that grew can merge again on the next frame.
