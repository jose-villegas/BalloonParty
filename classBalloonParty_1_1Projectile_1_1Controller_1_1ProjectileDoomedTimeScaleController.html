Detailed Description

Claims a global slow-motion time scale for a shot's doomed 'last breath' (see ProjectileDoomedStartedMessage).

The time-scale value is driven by an animation curve sampled on normalized doomed progress (elapsed / duration), so the slow-mo can ease in and out instead of snapping to a flat value. The slow-mo is world-wide, so it plays only while the doomed ball flies alone (ProjectileRegistryExtensions.DoomedShotFliesAlone, the same rule the spawner and balancer hold to); with other balls in flight it is released and the doomed look stays on the ball. Each ball's last breath keeps running on wall time meanwhile, so a ball left alone resumes where its last breath now is, not from the start.
