static bool BalloonParty.Shared.Extensions.InputHelper.PointerIsOverUI ( )
staticpackage

True when the current primary pointer is over a uGUI element (a Button, a panel), so raw Input.GetMouseButton world handlers can ignore taps the UI already consumed.

Passes the active touch's fingerId on device (the no-arg overload only tracks the mouse pointer); falls back to the mouse pointer in the editor. Safe before an EventSystem exists (returns false).
