Detailed Description

Mutable per-flight state threaded through ShotSimulator.Simulate — passed by ref to every helper that mutates it (a by-value pass would silently drop the mutation).

Board/geometry inputs (working set, walls, dynamics, cruise config) and the timeline outputs (path/timestamps) are deliberately NOT here — this is flight-local scoring/motion state only.
