Detailed Description

Where a shot leaves from, readable outside the thrower's own scope.

ThrowerView lives in ThrowerLifetimeScope, a child of the game scope, so systems registered above it — ItemAssigner, which needs a launch point to plan a shield chain from — cannot inject it. So it is a plain game-scope singleton the thrower fills in.

Vector2 IShotOrigin. BalloonParty.Thrower.ThrowerOriginProvider.RestingPivot
getprivate

The point the cannon turns about when it is at rest.

The muzzle sits straight ahead of it along the aim, so the line of every shot, whatever its angle, passes through this one point.

Captured once, when the thrower starts, and not read off the cannon as it stands: the cannon rises half a unit as it enters and is punched back by each shot's recoil, and a layout planned in either moment would be planned for a cannon that is not there when the level is played.

Implements BalloonParty.Shared.IShotOrigin.
