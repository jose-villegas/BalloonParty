Detailed Description

Monotone piecewise-cubic scoring curve.

Authors cumulative score milestones at key levels; intermediate levels are interpolated via Fritsch–Carlson monotone Hermite (with cached tangents to avoid per-call allocation); levels beyond the last control point extrapolate via TailGrowthConfig. Per-segment mode overrides allow Linear, Convex, or Concave shapes.

A difficulty spike requires three control points: rise, peak, and return.

Cumulative milestone for a given level.

Total function over [0, ∞): level ≤ 0 returns 0; level < first CP ramps linearly from origin; between CPs uses Fritsch–Carlson monotone cubic; beyond last CP extrapolates via tail config.
