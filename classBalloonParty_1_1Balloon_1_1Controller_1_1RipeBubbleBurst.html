Detailed Description

A ripe cluster's two endings.

The ripple (Ripple) is a small bomb: one hit of IRipeBubbleSettings.RippleDamage to each balloon that takes it (RipeBubbleRule.RippleTakes) on a slot within IRipeBubbleSettings.RippleRadius of the burst's (RipeBubbleRule.RippleReaches), through IHitDispatcher as an item's hit goes, so score, items and pops behave as for any other hit. The hits carry DamageFlags.Ripple and the shot that burst the cluster, never DamageFlags.DirectHit. With them go the pieces a bomb's blast has, each at its own smaller scale: a shockwave nudge of the board, an inward pull then an outward shock on the disturbance field, and a flash of light. The foam, when its fuse runs out (PlanFoam, then HandOut): the cluster gives its bubbles to its six neighbours (RipeBubbleRule.PlanHandout), coats on plain balloons and bubbles to clusters with room, pops any left over and leaves the board, all without a hit, with a round press on the water. Only RipeBubbleService calls it, from its own tick.

int handout )
package

Carries out a handout from PlanFoam: each coat goes on, each neighbouring cluster's count goes up, leftovers pop with no effect on anything, and the cluster leaves the board as a merge's absorbed giver does, its view lingering while it plays the hand-out (RipeBubbleRule.FoamLeaveSeconds).

State only: no hit is dispatched, nothing scores, so nothing it does can reach back into RipeBubbleService. Bubbles are only moved, never made.

◆ PlanFoam()

int BalloonParty.Balloon.Controller.RipeBubbleBurst.PlanFoam ( Vector2Int slot,
int bubbles )
package

Where the bubbles of the cluster at slot go when its fuse runs out, as RipeBubbleBurstMessage.Handout carries it: a coat for each neighbour that takes foam (RipeBubbleRule.FoamTakes), up to IRipeBubbleSettings.CoatLayers, a bubble for each neighbouring cluster with room below IBalloonsConfiguration.BubbleMergeMax, and leftovers for the rest.

It fills no more clusters to the cap than the board has room for (RipeRoom): the others stop a bubble short. Called after the room has heard that this cluster ended, so with a ripening cooldown above 0 a hand-out fills none. Changes nothing.

Blasts round slot : hits every balloon within the ripple's radius that takes it, in column then row order, and returns how many hits landed (an outcome other than HitOutcome.None), as RipeBubbleBurstMessage.Reached carries it.

The bursting cluster has left its slot by now; a balloon the board has since moved there is in the blast like any other.
