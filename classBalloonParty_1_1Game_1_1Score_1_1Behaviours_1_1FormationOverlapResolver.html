Detailed Description

Pure, allocation-free pairwise overlap resolution for ShapeFormationTicker's BigScore formations — a lightweight, per-frame relaxation pass ("push circles apart"), not a real Lubachevsky-Stillinger solver.

No Unity-object or ShapeFormationTicker dependency, so it's independently testable against plain arrays. Concrete array parameters (not IReadOnlyList) so indexing inside the O(n²) loop is direct, not through the array- covariance interface shim.

This is a JACOBI relaxation: every pair reads the CALL's ORIGINAL centers and offsets only accumulate, never feed back into the same call — a 3+-body mutual overlap can overshoot in one call. That's deliberate, not a bug: this method itself holds no state and is called once per tick, so convergence-in-one-call was never the goal — the CALLER (ShapeFormationTicker.ResolveOverlaps) accumulates the returned offset into each formation's persistent FormationState.SeparationOffset across as many ticks as it takes to genuinely resolve a sustained overlap. Switching to Gauss-Seidel (feeding corrections back within the same call) would make the result depend on iteration order — which the caller's swap-remove pooling shuffles nondeterministically — so don't "fix" the overshoot that way.

Single relaxation pass over the first count entries: for every overlapping pair, splits the correction by moveWeights (0 = immovable — its partner absorbs the whole correction instead of a 50/50 split) and clamps THIS CALL's offset to radius * maxPushFractions[i] (per-formation, not a single shared value — two concurrent groups could author different settings).

This method holds no state of its own — every call reads only the centers passed in — the caller decides whether that's a one-shot fresh position or, as ShapeFormationTicker does, a persistent accumulator plus the last resolved offset; see that class's ResolveOverlaps for why a sustained overlap needs the latter.

Distances are measured in the XY PLANE ONLY (Z is zeroed before every distance/direction computation) — the board reads as flat 2D under an orthographic camera, but formation centers travel a large, camera-invisible Z distance toward the score-bar canvas as they fly. Resolving in 3D would judge two formations "apart" the instant their travel progress differs by even a couple of frames, silently defeating the cross-group case this exists for. Projecting to XY also leaves each candidate center's Z (the travel depth curve) completely untouched by the correction.
