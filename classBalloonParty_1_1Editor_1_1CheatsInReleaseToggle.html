Detailed Description

Menu toggle for the CHEATS_IN_RELEASE scripting define on the active build target.

While checked, release (non-development) builds compile the cheat console in — dev builds and the editor always have it. The define persists in ProjectSettings until toggled off, so turn it off before building anything meant to ship.
