Detailed Description

The board-global scoring inputs ShotSimulator.ResolveBalloonContact/ ShotSimulator.ResolvePopScore need — built once inside ShotSimulator.Simulate from its own parameters and threaded in from there down, replacing the three loose strings/list that used to thread the same distance (Shot Solver Accuracy Phase C §5).
