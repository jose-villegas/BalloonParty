◆ SmearDownscale

int BalloonParty.Configuration.Effects.IScreenSpaceLightSettings.SmearDownscale
get

Divisor applied to the capture resolution for the smear/work targets.

The light buffer is low-frequency (blurred, composited multiplicatively), so it tolerates running well below capture resolution — pass 1's box soften doubles as the upsample filter and the overlay samples it bilinearly.

Implemented in BalloonParty.Configuration.Effects.SceneLightFieldSettings.
