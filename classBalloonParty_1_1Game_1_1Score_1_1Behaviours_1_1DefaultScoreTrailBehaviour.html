Detailed Description

Byte-for-byte parity with the pre-seam pipeline: one pooled trail per point, fanned out into a scatter ring and staggered, each reporting a single point on landing.

◆ Begin()

void BalloonParty.Game.Score.Behaviours.DefaultScoreTrailBehaviour.Begin ( in ScoreTrailContext context)

Owns the group from spawn to final arrival.

The handler MUST: report arrivals via ScoreTrailContext.Reporter with true cumulative scores that sum to ScoreTrailContext.Points; register and unregister its own flights in ScoreTrailContext.Flights (the cinematic pauses/tracks the principal by its id); and return every pooled instance it spawned to the pool.

Implements BalloonParty.Game.Score.Behaviours.IScoreTrailBehaviour.

◆ GetPrincipalId()

TrailId BalloonParty.Game.Score.Behaviours.DefaultScoreTrailBehaviour.GetPrincipalId ( in ScorePointsGroupMessage msg)

The id the level-up cinematic waits on and matches arrivals against.

The handler nominates it because only the handler knows which of its visual objects spawns immediately and is therefore safe under the cinematic's bounded registry wait — for the staggered default fan-out that is the FIRST trail (msg.FirstScore); a carrier that spawns at once could nominate LastScore.
