Detailed Description

Lets the player poke the cloud/disturbance field with a finger on the launch screen while the game pre-warms — a small idle delight.

Active ONLY while NavigationState.Launch is current, so it stops the instant the game starts and the launcher unloads. Reuses the shared disturbance stamp (the same call the dev DisturbanceStampCheat uses); no CPU sim of its own.
