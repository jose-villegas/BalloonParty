static

Per-line heavy-entry counts for the initial fill.

Heavy types are round-robined onto the bottom line of each spacing -tall segment, deepest line first so an uneven count settles lower; the total banded is capped at (layer lines × columns ). Returns an all-zero array — the caller then falls back to the plain lightest-first gradient — when spacing < 2, there are no heavies, or the board is too short to hold a full segment.
