Detailed Description

One flight's tally of mushroom bounces, which MushroomChainRule reads and writes: how many hits count since the flight began or last touched a wall of the board, how many times it has bounced off a cap in that stretch, and which wall of caps was hit last.

The default value is a flight that has hit nothing.

It rides on the ball's flight and on the shot solver's simulated flight alike, so it is a plain value with no model behind it.
