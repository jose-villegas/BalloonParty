Detailed Description

Tracing a projectile's wall-reflected path ahead to test whether it stays clear.

The per-segment occupancy test belongs to the caller (live physics, analytic board sim, ...); this owns only the shared skeleton — reflect off each wall via WallLimits, stopping at the first blocked segment.
