Detailed Description

The cards a level-up deals and the run holds.

The hand opens when a level-up is presented (LevelUpPhase.Pending), and a pick is only held once that level-up advances the level (Transitioning); an aborted level-up voids the hand and any pick with it.

Empty when no level-up is pending or this one deals none, which the ceremony reads as "no screen". Seeded by the level, so a retry that reaches the same level-up with the same cards is dealt the same hand.
