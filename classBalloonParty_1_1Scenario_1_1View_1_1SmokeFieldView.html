Detailed Description

Renders the smoke field RT as animated smoke trails behind the cloud backdrop.

Place this on a GameObject with a MeshRenderer + MeshFilter; it creates a viewport-sized quad at startup and assigns the display material. The sorting order is set below the Scenario Background so the paint layer sits behind the clouds.
