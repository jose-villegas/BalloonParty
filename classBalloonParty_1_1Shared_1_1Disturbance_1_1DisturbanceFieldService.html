Sets the initial accumulator to offset01 × interval so this service's first render fires at a staggered time relative to other services.

reportImpact false suppresses the bush rustle — for constant emitters (rainbow/tough pulses) rather than one-off hits.

◆ StampCone()

void BalloonParty.Shared.Disturbance.DisturbanceFieldService.StampCone ( StampSource source,
Vector3 origin,
Vector2 direction,
int paletteIndex = -1 )
package

Stamps a cone from the source's profile: Interval-many stamps marched from origin along direction (spaced by Radius), the radius growing by RadiusGrowth and the strength fading by StrengthFalloff toward the tip.

Only the first (muzzle) stamp reports impact. RadiusGrowth/StrengthFalloff of 0 give a uniform line.

◆ StampShieldLoss()

void BalloonParty.Shared.Disturbance.DisturbanceFieldService.StampShieldLoss ( StampSource source,
Vector3 worldPosition,
float velocityT,
int paletteIndex = -1 )
package

Stamps the source's profile with radius+strength scaled by the shot's velocity-normalized velocityT (see IDisturbanceFieldSettings.ShieldLossVelocityCurve) — used for the projectile's shield-loss wall impact only.

An unauthored curve evaluates to 0 everywhere, so appliedValue = base until it's authored.
