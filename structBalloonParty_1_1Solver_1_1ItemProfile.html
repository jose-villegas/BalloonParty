Detailed Description

A hosted item's data-only identity + spin state — rides only ShotBalloonSnapshot.ForColorTarget/ ShotBalloonSnapshot.ForRainbowTarget (only BalloonModel implements IHasItemSlot, and even then only a coloured/rainbow one is scoped to carry an item this phase — a tough/static target never does).

SpinDegrees/SpinDegreesPerSecond are 0 for every item but a spinning Laser (see ISpinningItemVisual) — inert data until Phase C3 reads them.
