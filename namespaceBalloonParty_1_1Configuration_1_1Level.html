◆ SegmentMode

enum BalloonParty.Configuration.Level.SegmentMode
package

How LevelScoringCurve interpolates the segment following a control point.

All modes guarantee the curve passes exactly through both adjacent CPs.

Enumerator
Smooth 

Fritsch–Carlson monotone cubic (default). Smooth transition respecting adjacent slopes.

Linear 

Straight line between this CP and the next. Constant per-level increment.

Convex 

Accelerating (ease-in). Starts slow, ends fast — convex shape.

Concave 

Decelerating (ease-out). Starts fast, ends slow — concave shape.

◆ TailGrowthMode

enum BalloonParty.Configuration.Level.TailGrowthMode
package

How LevelScoringCurve extrapolates beyond its last control point.

Enumerator
Geometric 

Each level's increment grows by a fixed multiplier (geometric series).

Rate 1.0 = flat (constant increment); rate 1.1 = 10 % harder each level.

Linear 

Each level's increment grows by a fixed addend (arithmetic series).

Rate 0 = flat; rate 50 = +50 cumulative per level beyond last CP.
