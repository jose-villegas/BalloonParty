Detailed Description

Counts each ball's deflects off balloons since it last touched a wall, announces the run from DeflectChainRule.MinChain deflects on (DeflectChainMessage), and pays the ball a shield every IRunConfig.DeflectChainShieldEvery in a row.

A wall spends a shield, so it breaks the run; pops don't.
